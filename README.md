# msgeasy (TypeScript/JS)

Built-artifact mirror of `packages/sdk-ts` from [Inteligenai/msgeasy](https://github.com/Inteligenai/msgeasy).
Source, issues, and PRs live in that repo -- this one exists only so `npm install` can pull a
git-hosted release without a monorepo subdirectory in the way.

```bash
npm install github:Inteligenai/msgeasy-ts-sdk#v0.1.0
```

Pushed automatically by `.github/workflows/publish-sdk-ts.yml` on every `sdk-ts-v*` tag. Do not
edit here directly -- changes belong in the source repo.
